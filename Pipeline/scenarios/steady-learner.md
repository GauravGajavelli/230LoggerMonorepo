# The Steady Learner

## Student Archetype
A methodical, well-prepared student who progresses smoothly through all BST concepts. They read the assignment carefully, start with basic insertion, and build up to more complex operations without major setbacks.

## Expected Story Arc

### Phase 1: Getting Started (Runs 1-3)
Initial compilation issues are brief. The student quickly sets up the BST structure and gets basic code compiling.

### Phase 2: Core Operations (Runs 4-10)
Insert and basic tree property methods are implemented steadily. Tests pass in an incremental fashion — each run shows clear forward progress. No oscillation or regression.

### Phase 3: Intermediate Operations (Runs 11-15)
Contains, conversion, and deletion methods are tackled. The student maintains momentum with high pass rates. A breakthrough occurs around run 15 where multiple new tests pass simultaneously.

### Phase 4: Advanced Operations (Runs 16-20)
Iterators and edge cases are handled. The student finishes strong with nearly all tests passing.

## Expected LLM Assessment
- **Dominant episode type**: productive
- **Pattern**: incremental development
- **Intent distribution**: mostly "extending" with minimal "debugging"
- **No prolonged stuck episodes**
- **At least one breakthrough episode**
- **Smooth, upward trend in test passage**

## Validation Notes
This scenario represents the "happy path" — a student who doesn't need much help. The LLM should recognize this as a straightforward, successful assignment completion without flagging concerns.
