## Exam 1

- **Covers:** Sessions 1–5, Warmup and Stretching, Stacks and Queues, and Homeworks 1–2
- **Allowed resources:** For the written part, you may use half of one side of 8.5 × 11 paper — the goal is to let you use formulas but force you to summarize. For the programming part, you may use Eclipse (including programs you have written for CSSE230), the CSSE230 materials in Moodle, and the Java API documentation.

### Written Part (60–70% of exam)

- Finding exact and big-theta runtime of code snippets, knowing when and how to use a loop index table and summations
- More with big O, Θ, and Ω: true/false, using definitions to do proofs
- ADT/Collections: Choosing an ADT to solve a given problem and knowing its runtime
- Growable Arrays
- MCSS
- Something from the assignments, like binary search

### Programming Part (30–40%)

- Implementing an ADT using an array, nodes, or another ADT, **or**
- Writing an efficient algorithm to solve a simple array-based problem

## Exam 3

- **Allowed resources:** Same as Exam 1, except you may use one whole side of 8.5" × 11" paper.

### Topics

Written part is approximately 50% of exam, programming part is the rest.

- Through day 21, HW7, and EditorTrees milestone 3
- Binary trees, including BST, AVL, indexed (EditorTrees)
- Traversals and iterators, size vs. height including height-balanced trees, rank
- Recursive tree methods. One programming question will be a method that should only touch each node once for efficiency (like sum of heights and isHeightBalanced from HW5)
- Hash tables
- Heaps — basic concepts; not on programming part

## Final Exam

- **Allowed resources:** Same as Exam 1, except you may use both sides of one 8.5" × 11" paper.

### Content (Comprehensive, with more focus on last 3 weeks)

- Binary trees, including EBT, AVL, and rank
- Traversals and iterators, numeric properties
- PriorityQueues, Heaps and heapsort
- Issues in Hash table implementation
- Graph implementations
- Recurrence relations
- Sorting algorithms and analysis
- Algorithm analysis in general
- OO programming, using various data structures (lists, stacks, queues, sets, maps, priority queues)
- +/− with ADT implementation options (like we did for PQ — be specific with answers)

### Programming

- 1 tree with efficiency (but likely tougher than Exam 2)
- 1 graphs
- 1 array-based (heap, hash, or sort)
