## Question 1 — pruneFullSubtreesSize3 (20 points)

Add the following method to `BinarySearchTree.java`:

```java
public void pruneFullSubtreesSize3()
```

This method removes every **full size-3 subtree** from the BST in place. A full size-3 subtree
is a node that has **exactly two children**, both of which are leaves (neither child has any
children of its own).

After the call, every such subtree root should be replaced by `NULL_NODE`.

**Example — three-node tree (one full size-3 subtree at the root):**
```
    romeo
   /     \
 echo   tango
```
```java
BST<String> bst = new BST<>();
bst.add("romeo");
bst.add("echo");
bst.add("tango");
bst.pruneFullSubtreesSize3();
assertEquals("[]", bst.toString());   // entire tree removed
```

**Example — five-node tree (one qualifying subtree, one surviving node):**
```
      romeo
     /     \
  echo    tango
  /
alfa
```
```java
// After pruneFullSubtreesSize3():
// echo qualifies (two leaf children? No — echo has only one child here, so it does NOT qualify)
// romeo does NOT qualify (echo is not a leaf)
// → tree unchanged: "[alfa, echo, romeo, tango]"
```

Hint: consider which traversal order lets you determine whether a subtree qualifies *after*
already processing its children.

## Question 2 — shortestWordAlongPath (20 points: 12 correctness + 8 efficiency)

Add the following method to `BinarySearchTree.java`:

```java
public T shortestWordAlongPath(T target)
```

Starting at the root, follow the standard BST search path toward `target` (using `compareTo`,
exactly as `contains()` does) and return the element with the **fewest characters** encountered
along that path. Visit only the nodes on the single path — do not explore both subtrees.

Assume `T` is `String`. You may cast to `String` where needed.

**Example:**
```java
BST<String> bst = new BST<>();
bst.add("romeo");                                         // root
assertEquals("romeo", bst.shortestWordAlongPath("romeo"));

bst.add("echo");                                          // left child of romeo
assertEquals("echo",  bst.shortestWordAlongPath("echo")); // path: romeo → echo; "echo" shorter
assertEquals("romeo", bst.shortestWordAlongPath("romeo")); // path: romeo only
```

## Question 3 — countLeftNodesAtDepth (16 points)

Add the following method to `BinarySearchTree.java`:

```java
public int countLeftNodesAtDepth(int depth)
```

Return the number of nodes at the given depth that are **left children**. The root is at depth 0
and is never a left child. A node at depth `d` is a left child if its parent's left pointer points
to it.

**Example:**
```java
BST<String> bst = new BST<>();
bst.add("november");   // root (depth 0)
bst.add("foxtrot");    // left child of november (depth 1) ← left child
bst.add("tango");      // right child of november (depth 1) ← not a left child

assertEquals(0, bst.countLeftNodesAtDepth(0));  // root is never a left child
assertEquals(1, bst.countLeftNodesAtDepth(1));  // only foxtrot qualifies
```
