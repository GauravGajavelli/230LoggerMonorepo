## Programming part (55 points)

The Winter 2022-23 programming portion of Exam 3 was a BST tree-traversal problem implemented in a `BinarySearchTree` class plus its inner `Node` class. Students were asked to implement a single-pass O(n) recursive method named `numHeightAndDepthBothOddOrEven()` on the BST that returns the count of nodes for which the node's height and depth share the same parity (both odd, or both even). The recursive helper on the Node class returned a small container of `(height, count)`, propagating depth down and heights up so each node was visited exactly once.

The exact starter prompt and tests for this question were distributed via the GitHub Classroom invite link printed in the in-room exam handout. The closest publicly-available analogue with comparable structure is the practice problem set in `Exam3-practice.zip` (questions like `weightedheight` and `imbalances` use the same single-pass height-aggregation pattern), and the 2020-21 version of the exam in `Exam3-202130-computer.pdf`.
