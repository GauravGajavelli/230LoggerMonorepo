CSSE 230 students using IntelliJ encountered some problems with your testSupport logging files in the winter term. I was able to help them resolve these, but it took some time and effort that distracted from the learning process. 

This term, at least one student using IntelliJ encountered a bug caused by inconsistent versions between the junit-platform-engine library installed by IntelliJ with the quick fix "Add JUnit 5" and the junit-platform-launcher jar bundled with the starter code as part of your changes. I worked with the student today but was unable to find a workaround other than deleting the testSupport folder and commenting out its uses in the test classes. 

It is my opinion that we should shut this project down for now, that is, remove all modifications to the CSSE 230 assignment repos. If you find a more robust setup that isn't so error-prone, we can carefully evaluate whether to resume the project. 

Dr. Holly and other instructors, feel free to chime in if you have differing opinions. Let's aim for a decision by the end of the week so we can mitigate the impact on this term's students.
